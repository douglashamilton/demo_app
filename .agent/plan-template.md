# Development (execution) plan

Outline the development plan needed to build the application. 

Break down the application into single classes / components / vertical slices as required so that the solution can be built iteratively.

Each iteration is likely to require:
1. A spike investigation
2. Development work
3. Test creation
4. Execution and debugging

It is expected that the solution will be re-appraised upon each iteration and the plan updated. 

The plan needs to contain everything required for you (the agent) to generate the next vertical slice. 

The plan must advise you (the agent) to maintain a build log that serves as a running memory, documenting design decisions etc, that will be necessary to maintain context in later iterations. The build log must be recorded in  `../docs/` with the filename `log.md`.

After each iteration, the plan needs to inform the user of a manual test that can be performed to inspect the change.
